# WolfGalaxy — SpoTUI Community Theme

This package contains the files/assets for submitting WolfGalaxy through the SpoTUI theme browser.

## Theme
- Name: WolfGalaxy
- Style: black / violet / cosmic
- Accent: #8B5CF6
- Highlight: #B026FF
- Text: #E9D5FF
- Font: SpoTUI default
- Wallpaper opacity: 0.42
- ASCII SpoTUI logo: off
- Custom player bar: on
- Progress style: diamond

## Important
SpoTUI community themes are applied as a list of SpoTUI commands. The `theme.json` file is a convenient copy of the submission information; it is not itself a required SpoTUI runtime file.

Before submitting:
1. Create a public GitHub repository named `WolfGalaxy`.
2. Upload `assets/wolf-galaxy.png` and `preview.png`.
3. Replace `YOUR_GITHUB_USERNAME` in `theme.json` and `commands.txt`.
4. In the SpoTUI theme browser, sign in with GitHub and use **Add yours**.
5. Enter the theme name/description and paste the commands from `commands.txt`.
6. Use `preview.png` as the theme preview if the submission form asks for one.

After publication, SpoTUI can apply the theme through its theme system; the project documents `tui -t pull <theme_id>` for published themes.
